# Controls

Keyboard bindings are data-driven, persisted locally, and remappable in-game with `F2`. Press a new key for each action or Tab to retain the current binding.

| Action | Keyboard default | Gamepad | Mouse |
| --- | --- | --- | --- |
| Move / eight-way aim | WASD or arrows | left stick; right stick aims | — |
| Jump / wall jump | Space or Z | A | — |
| Air dash | Left Shift or X | X | — |
| Slide / rail grind | C or Left Ctrl | B | — |
| Dive | V | D-pad down | — |
| Grapple / release | E | right shoulder | left button, free aim |
| Cut / drill / recoil | Q | left shoulder | right button, free aim |
| Push / pull object | R | — | aim plus R |
| State and hand debug | F3 | — | — |
| Generation/collision overlay | F4 | — | — |
| Hot reload level JSON | F5 | — | — |
| Return to menu / quit | Escape | — | — |

The full movement and tool kit is always present. Landing or valid wall contact refreshes airborne dash and grapple resources. The debug overlay exposes current/previous state, transition reason, velocity, grounded/wall state, buffered input count, resources, hand distance/closing speed, active contacts, IK failures, and reload status.
