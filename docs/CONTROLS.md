# Controls

Bindings are editable from the in-game binding panel and persisted as readable JSON.

| Action | Keyboard / mouse | Gamepad |
|---|---|---|
| Move / crouch / aim | WASD or arrows | left stick / D-pad; right stick aims |
| Jump / mantle | Space | A |
| Dash | Left Shift | X |
| Wall cling / grapple modifier | Left Ctrl | left shoulder |
| Active grapple | right mouse | right shoulder |
| Dig | left mouse or F | X while grounded/near terrain |
| Slide | C | B |
| Place rope | R | Y |
| Bomb | Q | right trigger |
| Look | mouse / movement direction | right stick |
| Debug/editor | F1 | Back + Start |
| Pause | Escape | Start |

Editor controls appear in the overlay because their meaning depends on the selected tool.
