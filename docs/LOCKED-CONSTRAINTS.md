# Vertical-slice constraints

- Fedora Linux, MonoGame DesktopGL, C#, stable 60 Hz fixed update.
- One 3–5 minute seamless open-air badlands ascent with a clear summit.
- Chunked authoritative square tiles; free-position entities.
- Full movement kit from frame one; no movement upgrades.
- Reusable directional terrain-breaking punch; limited placed ropes and bombs.
- Material-driven hardness, friction, climb, and destruction behavior.
- Three selectable deterministic generator variants using one output format.
- Reject unsolvable generated worlds; never patch them with a secret route.
- Same seed geometry in Easy and Hard; only pressure/tuning differs.
- One burrower enemy and one brittle collapsing hazard.
- Seeded procedural history shown through environmental traces and optional discoveries.
- Persistent Archive records knowledge only.
- In-game editor, readable JSON round-trip/export, and plain-file playtest evidence.
- Keyboard, mouse, and gamepad share remappable named actions.
- No audio, runtime LLM, cloud dependency, checkpoint, extra biome, or deep combat system.
