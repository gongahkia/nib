# Sublime Text guide

Nib provides generated `Nib Light.sublime-color-scheme` and
`Nib Dark.sublime-color-scheme` files. They cover baseline syntax scopes,
markup, selections, search, guides, diagnostics, and both gutter and content
diffs.

## Install

In Sublime Text, open **Preferences → Browse Packages…**, enter the `User`
directory, and copy both files from this repository's `sublime/` directory.
Choose **Preferences → Select Color Scheme…**, then select **Nib Light** or
**Nib Dark**.

A Sublime color scheme controls the editor surface and syntax. Tabs, sidebars,
buttons, and other application chrome are controlled by Sublime's separate UI
theme, so Nib deliberately does not claim to recolor those components.

## Remove

Select another color scheme, then delete the two Nib files from the `User`
package directory.
