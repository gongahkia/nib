# Runtime architecture

The authoritative world is a deterministic square tile grid partitioned into 16×16 chunks. Tiles store material, accumulated damage, flags, and provenance references. Free-position entities query and mutate that grid; no render polygon owns collision state.

Generation is a seed/version/parameter function behind one interface; the current algorithm contract is `badlands-v3`. Heightmap emphasizes broad boundary escarpments and long silhouettes, Cellular emphasizes fractured local outcrops and material irregularity, and Layered combines those systems with the densest embedded ruin provenance. Sixteen solid materials are distributed through altitude, warped strata, local cells, exposed surfaces, and old ruin fabric; every material remains in a one-hit or two-hit tool tier. All generators emit the same `TileWorld`. Routes include switchbacks, short descents, lateral spans, connected talus, and optional longer detours. The validator checks one-tile spawn/body clearance, landing support, route variety, conservative transitions, summit attachment, and diggability using no consumables. Failed candidates are rejected and the next derived seed is visible in debug state.

The game loop uses MonoGame's fixed timestep at 60 Hz. Input is translated into named actions before controllers consume it. `PlayerController` owns the 18×22 px standing body inside a 24×24 px tile, its 18×14 px crouched body, and explicit movement transitions. Terrain collision uses swept one-pixel axis steps, including dash termination at the first collision. Ledge catches validate a reachable clear mantle destination before committing. Long falls remove one heart after 360 px/s and apply a 0.4–0.7 second stun rather than escalating health damage. Active grappling is absent. Placed ropes are scarce entities with an authoritative solid anchor tile. An upward, aim-assisted throw can reach an exposed overhang up to six tiles from the player's feet; a close exposed ledge remains a valid anchor. Vertical input automatically attaches, rejected placement preserves inventory, and terrain destruction detaches ropes whose anchors no longer exist. Tool targeting derives the immediately adjacent cardinal tile from the current collision body, allowing physical swings above and below without reaching through terrain. Mutations dirty only affected chunks.

Runtime persistence normally stores generation configuration and mutable run metadata. The editor can export a complete indented JSON snapshot containing tiles, chunks, materials, entities, hazards, relics, history references, and mutations. The permanent Archive is separate from run state and stores discoveries only.

Telemetry writes one self-contained directory per session. Frame samples, event records, screenshots, metadata, and a world snapshot share frame/time identifiers. Full deterministic replay is intentionally out of scope.

Rendering uses generated PNG sheets, nearest-neighbour sampling, a fixed 0.875× world camera with whole-screen-pixel translation, a global logical palette with a restrained badlands extension, authored foreground dithering, and a simple screen-space atmospheric dither. The live visual-selector state is presentation-only and persists separately from worlds. Imported 8px, 16px, and 32px terrain sources pass through pack-specific adapters into the same 24px render destinations; player and environment selections are independent. Missing local-only art falls back to the original runtime sheets. The HUD remains at the 640×360 logical resolution while the world view exposes roughly 14% more width and height. No custom effect is required for the slice.
