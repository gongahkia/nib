# Sprite generation and replacement

All shipped runtime sprites are original deterministic placeholders generated by `python3 tools/generate_sprites.py`. Pillow draws exact palette-slot colours with hard edges and no resampling. Each asset family has a transparent runtime sheet and a matching white-background source sheet. Replace a sheet without changing its cell size, frame order, or filename; `assets/sprites/manifest.json` is authoritative.

The optional **Ashen Pilgrim** player is project-owned original art generated through Aseprite MCP rather than Pillow. Its editable source is `assets/sprites/aseprite/ashen_pilgrim.aseprite`; `tools/aseprite/generate_ashen_pilgrim.lua` deterministically constructs all 25 frames using the global Summing palette. The exported locomotion and traversal sheets preserve the exact 24×24 cells and frame order used by `SpriteLibrary`, so selecting it changes presentation only. It covers idle, run, takeoff, ascent, apex, fall, land, crouch, crawl, slide, ledge, mantle, wall cling/jump, dash, rope, both dig phases, bomb, hurt, and death.

The 2026-09-07 generation pass used `diivi/aseprite-mcp` at commit `90d1696a7e41edff89bbd0823ae6a5f86c114bcc` in a disposable `/tmp` checkout with `uv sync --frozen`. The server was pointed at Aseprite 1.3.18.3 through `ASEPRITE_PATH`; its upstream suite passed 121 tests. MCP's `run_lua_script` performed the batched draw, `set_tag` created the `locomotion` and `traversal` ranges, and `export_spritesheet` produced the two transparent runtime PNGs. No MCP server, Python environment, or Aseprite dependency is included in the game. Rerunning the Lua source requires an existing licensed Aseprite installation.

The runtime also supports an optional local visual comparison library opened with `K`. It discovers assets beneath `third_party/art/` without copying restricted raw files into build output. Player and environment packs are selected independently. GandalfHardcore supplies selectable male/female modular body, legs, torso, feet, and hair sheets. Merakintsugi's local-only free sample supplies an additional player comparison, but it contains only idle and walk animation, so all other states use walk frames and it is not a final-art candidate. Environment choices include Summing Original, Gandalf Overworld, Adve, Monochrome Caves, Pixel Fantasy Caves, Stone Ruins, and Dracula's Manor. Pack-specific render adapters preserve the authoritative 24px terrain grid while applying 8px, 16px, or 32px source art with nearest-neighbour sampling. They select authored top, bottom, side, and interior roles rather than arbitrary atlas cells; fragment-only Stone Ruins art is limited to ruin-compatible terrain, and Pixel Fantasy's transparent rock art is limited to exposed edges. Gandalf's flat interior colour is removed in memory so Summing's material palette stays visible, and imported characters are scaled to remain approximately one tile tall. Missing Summing-specific traversal poses are deliberately mapped to the closest supplied frames. These are playtest comparisons, not the canonical replacement pipeline; the original manifest-backed sheets remain the complete fallback.

## Extraction workflow for future source art

1. Generate on a plain pure-white background with separated cells and no shadows.
2. Resize to the intended pixel grid with nearest-neighbour sampling only if the model output needs reduction.
3. Remove only contiguous pure-white background pixels; preserve intentional internal white detail.
4. Place frames in manifest order on a transparent RGBA sheet.
5. Quantize manually to the named palette slots; do not introduce near-duplicate colours.
6. Run `make assets`, inspect at 1× and the in-game 2× scale, then verify alpha and cell dimensions with `python3 -m PIL` or another PNG inspector.

Never request replicas of their characters, symbols, palettes, or assets.

## Reference boundary

The named games are communication references only. No source sprite, trace, pose sheet, faction symbol, proprietary palette, or third-party art is an input to the generator. The generated placeholders remain project assets and can be replaced independently by preserving the manifest contract.
