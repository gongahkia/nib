# Sprite generation and replacement

All shipped runtime sprites are original deterministic placeholders generated by `python3 tools/generate_sprites.py`. Pillow draws exact palette-slot colours with hard edges and no resampling. Each asset family has a transparent runtime sheet and a matching white-background source sheet. Replace a sheet without changing its cell size, frame order, or filename; `assets/sprites/manifest.json` is authoritative.

The tracked `source/summing-concept-white.png` was generated once with ChatGPT image generation as mood/shape ideation. It is not sampled or shipped at runtime. Runtime sheets remain reproducible without any model or cloud access.

## Extraction workflow for future source art

1. Generate on a plain pure-white background with separated cells and no shadows.
2. Resize to the intended pixel grid with nearest-neighbour sampling only if the model output needs reduction.
3. Remove only contiguous pure-white background pixels; preserve intentional internal white detail.
4. Place frames in manifest order on a transparent RGBA sheet.
5. Quantize manually to the named palette slots; do not introduce near-duplicate colours.
6. Run `make assets`, inspect at 1× and the in-game 2× scale, then verify alpha and cell dimensions with `python3 -m PIL` or another PNG inspector.

Use Nidhogg, Caves of Qud, Dwarf Fortress, and PICO-8 only as high-level vocabulary for silhouette economy, restrained pixel count, limited colours, and state readability. Do not imitate or reproduce any character, symbol, object, palette, or asset from those works. Mood: lonely, melancholic, sacred, grotesque, beautiful, mysterious. Palette: near-black blue, bruised stone violet, oxidized red, bone sand, pale gold, salt-glass cyan. No text, labels, logos, UI frames, watermark, drop shadows, checkerboard, gradients, transparency simulation, humour, generic medieval fantasy, painterly texture, or 3D rendering.

## Reference boundary

The named games are communication references only. No source sprite, trace, pose sheet, faction symbol, or proprietary palette is an input to the generator. The placeholder code and images are dedicated to the project under CC0-1.0 so later production art can replace them cleanly.
